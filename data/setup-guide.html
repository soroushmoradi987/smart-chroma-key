Smart Chroma Key

Version 1.4.1 · Classic + AI · OBS Studio

English guideراهنمای فارسی

Set up your camera

  1. Quit OBS before installing. Run the installer for your operating system and follow the steps.
  2. Start OBS Studio 31 or later. Right-click your camera source and choose Filters.
  3. Under Effect Filters, press + and select Smart Chroma Key.
  4. Choose a Processing method using the guidance below. Each method keeps its own settings.

Classic — for a green or blue screen

Choose Smart Chroma Key (Classic). Set Screen Type to Auto Detect and press Analyze Screen Now. Light the screen evenly and keep the subject away from it. Adjust hair, edge and spill controls gradually while inspecting your actual scene.

AI — person background removal

Choose AI - Robust Video Matting (RVM). The model is included and runs on your computer. Allow a few seconds for the first result. Select the screen color if you use a green or blue backdrop; otherwise choose None. Increase Halo cleanup only as needed: strong cleanup can remove fine hair.

Set Preview background to Transparent for normal use. White, Black and Alpha matte are inspection views, not the background of your final scene.

macOSWindows
Universal plugin for Apple silicon and Intel. AI uses Core ML. Classic also offers Apple Vision person and hair protection.64-bit Windows 10/11. AI runs on the CPU. Start at 640 - balanced; choose 320 for a slower CPU or 960/1280 for more detail. Higher resolution can lower the AI frame rate.

Installation locations

Mac (your account):
~/Library/Application Support/obs-studio/plugins/smart-chroma-key.plugin

Windows (all users):
C:\ProgramData\obs-studio\plugins\smart-chroma-key

If the filter is missing or unchanged

Restart OBS normally, outside Safe Mode. Check Effect Filters, not the Sources list. Avoid keeping old copies of this plugin in other OBS plugin folders. Use Help → Log Files → View Current Log and search for Smart Chroma Key. Send the plugin version, OBS version and log with a support request.

Remove the plugin

Quit OBS. On Windows, use Settings → Apps → Smart Chroma Key → Uninstall. On Mac, move only smart-chroma-key.plugin from the folder above to the Trash. Your OBS scenes are not removed.

No account or online AI service is required. Camera frames stay on your computer. Real-camera results and speed depend on lighting, footage and hardware.

راه‌اندازی دوربین

  1. پیش از نصب، OBS را کامل ببندید. نصب‌کنندهٔ سیستم‌عامل خود را اجرا کنید و مراحل را ادامه دهید.
  2. OBS نسخهٔ ۳۱ یا جدیدتر را باز کنید؛ روی منبع دوربین راست‌کلیک کنید و Filters را بزنید.
  3. در بخش Effect Filters روی + بزنید و Smart Chroma Key را اضافه کنید.
  4. روش پردازش را از Processing method انتخاب کنید. تنظیمات هر روش جداگانه نگه داشته می‌شود.

Classic؛ برای پردهٔ سبز یا آبی

روش Smart Chroma Key (Classic) را انتخاب کنید. Screen Type را روی Auto Detect بگذارید و Analyze Screen Now را بزنید. پرده را یکنواخت نور بدهید و از آن فاصله بگیرید. تنظیمات مو، لبه و حذف بازتاب رنگ را کم‌کم و با مشاهدهٔ تصویر تغییر دهید.

AI؛ حذف پس‌زمینهٔ فرد

گزینهٔ AI - Robust Video Matting (RVM) را انتخاب کنید. مدل همراه نصب‌کننده است و روی رایانهٔ خودتان اجرا می‌شود. بار اول چند ثانیه صبر کنید. اگر پردهٔ سبز یا آبی دارید، رنگ آن را انتخاب کنید؛ در غیر این صورت None را بگذارید. افزایش زیاد Halo cleanup ممکن است تارهای ظریف مو را حذف کند.

برای استفادهٔ عادی، Preview background را روی Transparent بگذارید. گزینه‌های سفید، سیاه و آلفا برای بررسی لبه‌ها هستند.

در مک، AI از Core ML استفاده می‌کند. در ویندوز، AI روی CPU اجرا می‌شود؛ با وضوح ۶۴۰ شروع کنید و برای رایانهٔ ضعیف‌تر ۳۲۰ را انتخاب کنید. وضوح بالاتر جزئیات بیشتری دارد ولی ممکن است سرعت را کم کند. گزینهٔ محافظت Apple Vision مخصوص مک است.

اگر افزونه دیده نمی‌شود

OBS را کامل ببندید و دوباره، خارج از حالت امن، باز کنید. افزونه در Effect Filters است، نه فهرست منبع‌ها. نسخه‌های تکراری قدیمی را در پوشه‌های دیگر OBS نگه ندارید. برای گزارش خطا، از Help → Log Files → View Current Log استفاده کنید و نسخهٔ OBS و افزونه را هم بفرستید.

حذف افزونه

ابتدا OBS را ببندید. در ویندوز از بخش برنامه‌های Settings، افزونه را Uninstall کنید. در مک فقط پوشهٔ smart-chroma-key.plugin را از مسیر نصب بالا به سطل زباله منتقل کنید. صحنه‌های OBS حذف نمی‌شوند.

حساب کاربری و سرویس آنلاین لازم نیست؛ تصویر دوربین روی رایانهٔ شما می‌ماند. کیفیت و سرعت به نور، تصویر و سخت‌افزار بستگی دارد.
